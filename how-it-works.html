How it works

Batch tracking groups produce into a batch with an ID, then records each step the batch goes through. A shopper can later look up the ID and read the recorded steps.

The idea in four steps

  1. Harvest. A batch is created and given an ID.
  2. Pack. The batch is packed and the ID is attached to the packaging.
  3. Transport. Movement of the batch is recorded.
  4. Arrival. The batch is received at the point of sale, where its ID can be looked up.

What this demo does

  • Filters a sample produce catalogue by category.
  • Looks up three sample batch records stored in the page's own files, and shows clear messages for invalid or unknown IDs.

What this demo does not do

  • It does not show real farms, suppliers, prices, certifications or deliveries.
  • It has no sign-in, ordering or payments.
  • It has no GPS tracking or QR scanning.
  • It does not store or save anything you enter.

A real system would need a backend (a server and database) so that approved people can add records, plus a way to print and scan codes. That is not connected here.
